إعداد Dashboard V5 مع Firebase
1. في Firebase Console > Firestore Database > Rules: انسخ محتوى firestore.rules واضغط Publish.
2. في Authentication > Settings > Authorized domains: أضف نطاق GitHub Pages الخاص بك (مثال: kalelalsaeed442-hub.github.io).
3. ارفع محتويات مجلد dashboard_team إلى جذر مستودع GitHub Pages، مع جميع الملفات والصور.
4. سجّل الدخول عبر Admin بالبريد kalelalsaeed442@gmail.com وكلمة المرور التي أنشأتها في Firebase Authentication.
5. لا تستخدم 13810 ككلمة مرور عامة. UID المدير محدد في قواعد Firestore.
6. في أول استخدام، احفظ بيانات معمل وأحد أعضاء الفريق لإعداد المستندين المشتركين. البيانات الأصلية تظهر تلقائيًا إلى حين أول حفظ.
7. يتطلب تشغيل النظام اتصالًا بالإنترنت؛ صفحات GitHub Pages تعمل عبر HTTPS.
8. هذا الإصدار يحفظ بيانات المعامل والفريق مركزيًا، ولا يغيّر بقية التصميم. عند تحديث البيانات من جهاز آخر يعيد تحميل الصفحة لعرض النسخة الجديدة.
9. هام: الحسابات الجديدة تنشأ بواسطة Firebase Authentication؛ لا يمكن حذف حساب Auth بالكامل من واجهة الويب دون خادم موثوق. يمكن للمدير تعطيل صلاحية التحرير من Firestore يدويًا.
10. ملاحظة تدقيق: سجل النشاط مركزي لكنه ليس سجلًا معاملاتيًا مضمونًا 100%، فقد تنجح كتابة البيانات وتفشل كتابة السجل. للضمان الصارم يلزم Cloud Functions أو كتابة مجمّعة بقواعد أكثر إحكامًا.
